# One Line, No Deadline Met — "I didn't miss the deadline — I just gave it a head start out of professional courtesy."

Built for the [make.fun "One Line, No Deadline Met" bounty](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce) — a program that writes one single-line joke giving an excuse for a missed deadline.

## The line

> I didn't miss the deadline — I just gave it a head start out of professional courtesy.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set). Node 22+, no network, no dependencies.
